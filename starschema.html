What is an OLAP Cube?

An OLAP Cube is a multi-dimensional structure used to store data for fast analysis. Unlike a 2D spreadsheet (rows and columns), a cube allows you to view data across many dimensions simultaneously.

  • Edges: Each edge represents a Dimension (e.g., Time, Product, City).
  • Cells: Every point inside the cube is an intersection containing a Measure (e.g., Sales).
  • Pre-aggregation: Cubes often calculate totals in advance so queries finish in milliseconds.

Fact vs Dimension Tables

The Fact Table

  • Located at the center of a schema.
  • Contains Foreign Keys to dimensions.
  • Contains Measures (the "facts").

Dimension Tables

  • Located at the edges.
  • Contains Primary Keys.
  • Contains Attributes (Product color, Shop manager).
